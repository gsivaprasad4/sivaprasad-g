### 🐧 Linux Health Analyzer

**Python | Linux | Git | GitHub Actions | JSON | Unit Testing**

Developed a Python-based Linux system health monitoring tool to collect and analyze system metrics, including memory usage, disk utilization, system uptime, top processes, and failed services.

**Key Features:**
- Collects Linux system health metrics and generates timestamped JSON reports.
- Implements configurable warning and critical alert thresholds using JSON configuration.
- Performs automated health assessments and identifies potential system issues.
- Includes unit tests using Python's `unittest` framework.
- Integrates GitHub Actions CI to validate configuration, run unit tests, and check Python syntax on pushes and pull requests.

**Testing:** All 7 unit tests pass locally, and the GitHub Actions CI workflow passes successfully.
